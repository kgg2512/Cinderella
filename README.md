# Cinderella

**G2 Company Ltd 공식 프로젝트**

> 명품을 소유하지 않아도 즐길 수 있다.  
> *Luxury without ownership.*

P2P 명품 렌탈 플랫폼. 당근마켓 방식의 명품 단기 렌탈 앱.

**[https://cinderella-iota.vercel.app](https://cinderella-iota.vercel.app)**

## 제품 개요

| 항목 | 내용 |
|------|------|
| 유형 | P2P 명품 렌탈 앱 |
| 타겟 | 명품 경험을 원하는 MZ세대 |
| 모델 | 개인간 직거래 렌탈 (당근마켓 구조) |
| 수익화 | 거래 수수료 |

## 핵심 기능

- 명품 아이템 등록 / 렌탈 요청
- 사용자 인증 및 평가 시스템
- 보증금 / 렌탈료 처리
- 아이템 검색 및 위시리스트

## 기술 스택

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: Supabase (Auth + DB + Storage)
- **배포**: Vercel

## 개발 현황

| Phase | 내용 | 상태 |
|-------|------|------|
| Phase 1 | 프로토타입 — P2P 렌탈 기본 흐름 | ✅ 완료 |
| Phase 2 | 결제 연동 + 보증금 처리 | ⏳ 예정 |
| Phase 3 | 앱 런칭 (iOS/Android) | ⏳ 예정 |
