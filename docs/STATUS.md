## 4. By Rotation 대비 비교 (요약 — 상세는 BENCHMARK_BY_ROTATION.md)
**핵심 통찰:** 신데렐라는 By Rotation을 복제하다 막힌 게 아니라 **이미 다른 동물.** 결제는 더 영리하게(한국 적법) 비켜갔고, 진품·약관은 By Rotation보다 더 센 걸 약속하고 아무것도 안 만든 모순 상태.

| 축 | By Rotation | 신데렐라 | 판정 |
|---|---|---|---|
| 신뢰축 | 사람 검증(Stripe KYC), 물건 안 봄 | 사람·물건 무검증 + 약관만 감정 의무 | 🔴 모순 |
| 결제 | Stripe 단일(정산·수수료·KYC) | 플랫폼 무자금, 토스/카카오 딥링크 직송금 | 🟢 한국 적법(대가: 수익 0·구매보호 0) |
| 진품/감정 | 안 함(사람검증 대체) | 안 함(약관만 의무화) | 🔴 신고→삭제 필요 |
| 기능 | 소셜피드·예약·리뷰 | 거래 7단계·신고·증거사진 | 🟢 충실 |
| 로그인 | Google·FB·이메일 | Google 단독, Apple 없음 | 🟡 iOS 숙제 |
| 법적환경 | 영미 safe harbor | 상표법 §108·전상법 §20의3 적용 | 🔴 한국 고유 리스크 |

**"미국 되니 한국도 된다"는 거의 0의 증명력** — By Rotation의 세 엔진(Stripe 개인정산·사람검증 KYC·영미 safe harbor)이 셋 다 한국 국경에서 부서짐.

## 5. 결제 / 기능 / 진품 상태 한눈에
- **결제:** 🟢 **현 구조 유지가 정답.** 플랫폼이 돈을 안 만지고 토스 딥링크 개인 직송금 = 이미 한국 적법. **By Rotation식 Stripe 복제 시도 금지.** 과금은 유저·물량 붙은 뒤 국내 PG(토스페이먼츠·KG이니시스)로. 보증금도 플랫폼 보관 금지(전자금융거래법 자금보관 규제) → 개인 직거래 유지.
- **기능:** 🟢 거래루프 충실. 콜드스타트(DB 0건) 시 온도점수가 비어 무용 → 초기 큐레이션 페어리 시딩 + 검증 뱃지 필요.
- **진품여부:** 🔴 **최대 약점.** 사람·물건 둘 다 미검증. 한국형 대안 = ⓐ페어리 PASS/통신사 본인인증(Stripe Identity보다 싸고 적법) ⓑ물건 신고기반 사후검수 + 고가품 선택적 외부감정 제휴(라벨·한국명품감정원). "정품 보장" 표현 금지(표시광고법) → "개인간 거래, 정품 보장 아님" 명시.
