## 3. 횡단 평가
1. **디자인 시스템 일관성 — 낮음.** 팔레트(골드/올리브/블랙/크림)는 통일. 그러나 타이포 위계 이원화(진입부만 이탤릭 세리프, 내부 다수 볼드 산세리프), 여백 리듬 불일치(빈 상태 컴포넌트 부재로 "미니멀" 아닌 "미완성"), `₩` 글리프 결함.
2. **브랜드 아이덴티티 — 진입부 편중.** 로그인·홈·PDP는 아스피레이셔널 명품 전달, 내부는 브랜드 각인 옅음. "마케팅 스킨 + 표준 CRUD" 구조에 가까움.
3. **IA/내비 — 기본기 OK, 구멍 존재.** 하단탭 6개 390px 내 수용 확인. 단 safety orphan·PDP 전환동선 미표시·"좋아요" 용어 불일치.
4. **접근성 — 정적 양호, 정량 미검증.** `prefers-reduced-motion` 코드 존재, `aria-label` 28회. **색대비·포커스·터치타깃 정량(axe) 미실시 = 미확인.**

## 4. 재시작 시 UI/UX 우선순위 (회장 결정 대기)
1. **깨진 것 고정 (최저 난이도·즉시 신뢰)** — `/safety` page.tsx 신설(로직 존재), `items/new` `₩` 글리프 수정. 반나절.
2. **에디토리얼 아이덴티티 내부 확장 (브랜드 임팩트 최대)** — 진입부 세리프 헤더·톤을 채팅/거래/찜/설정에 일관 적용. 디자인 토큰(헤더 서체·카드·빈 상태) 통일.
3. **빈 여백·전환 동선 정리 (사용성 직결)** — 빈 상태 디자인(일러스트+카피+CTA), PDP에 "예약하기" 또는 "채팅으로 예약 문의" 명시.
