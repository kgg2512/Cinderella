# BMD — 신데렐라 × MIT Disciplined Entrepreneurship 24단계

> **BMD (Business Model Development)** = 사업모델을 "주장"이 아니라 "고객 증거"로 검증하는 상시 도구.
> MIT 「Disciplined Entrepreneurship」(Bill Aulet, 한국어판 *스타트업 바이블*) 24단계를 신데렐라에 적용한 워킹 문서.
> 실제 채점 플랫폼 = beachhead-psi.vercel.app("신사업개발 교육 시스템"). Notion 상위 문서: 내부 프로젝트 **BMD**.
> 최초 작성 2026-07-19. 아래 결정은 **방향·가설**이며 단계별 고객 증거로 검증 예정(미확정).

## 0. 관통 논리 (먼저 이해)

"모두"를 겨냥하지 말고 **단 하나의 거점시장(beachhead)** 에 집중 → 지배 → 확장. 4대 규율:

1. **시장 견인 우선** — 고객 고충에서 출발(기술 주도보다 성공률↑)
2. **1차 시장조사가 전 과정의 연료** — 건물 밖으로 나가 실제 고객을 만난다
3. **정성(작은 n) → 정량(큰 n)** 순서
4. **말이 아니라 행동·돈으로 검증**

24개 관문이 반복해서 압박하는 3가지: **① 구체성**(모두→1인 페르소나) · **② 증거**(내 생각이 아니라 실제 고객) · **③ 경제성**(LTV > 고객획득비용).

## 2. 신데렐라 1차 적용 (2026-07-19 회장 결정·가설)

| 항목 | 회장 결정 · 가설 | Alpha 판정 |
|---|---|---|
| **레종데트르(왜)** | 돈이 아니라 "작지만 확실한 수요". 명품은 매년 비싸지고 수요↑인데 — 산 사람은 아까워 데일리로 못 쓰고, 못 산 사람은 구매 전 경험할 방법이 없다. 기존 B2C 렌탈은 비싸고 불편 → P2P로 해소 | ✅ 0단계 합격 수준(시장 견인) |
| **거점 방향** | "일회성 명품 경험 수요"로 세분화 | ⚠️ 축은 맞으나 그 자체는 거점 아님(이질 집단) → 한 단계 더 좁혀야 |
| **거점 1순위 가설** | (Alpha 추천) 결혼식 하객 20~30대 여성 — 강한 트리거·서로 입소문·고가 1회성 부합 | 1~2단계 8기준 비교표로 검증 |
| **페르소나 우선순위** | 수요측(빌리는 사람=신데렐라) 먼저. 공급 콜드스타트=회장 본인+친구 명품(고야드 등) 시딩 | ✅ 유효(닭·달걀 자가해결) |
| **진품검증(B1)** | 패피스 또는 **한국명품감정원** 등과 MOU → 공인기관 감정 보증 하 P2P | 방향 good. ⚠️ MOU≠구현: 약관 즉시 임시교정 필요 |
| **통신판매중개업(B3)** | 법인 설립 중 → 곧 신고 예정 | 타이밍 OK. ⚠️ "무자금이라 해당없음"은 오해(중개행위+거래규모 기준, CLO 확인) |
| **BM(수익)** | 유저 규모 확보 후 광고 | ❌ 광고 단독은 니치에 취약 → 15단계에서 거래수수료·제휴수수료 등과 재검증 |
| **고객검증(1A·9·23)** | 회장 친구망(명품 보유)으로 시딩+1차 인터뷰 | ⚠️ 절반만 유효: 친구=사회적 수용성 편향 → 모르는 목표고객으로 확장 필수 |

**진행 상태(플랫폼):** 0·1·1A 열림 / 2~24 잠김(앞 단계 통과 시 순차 해제).
