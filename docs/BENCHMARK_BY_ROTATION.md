# 신데렐라 vs By Rotation — 벤치마크 비교 & 보완점

> **출처:** 2026-06-23 세션 분석(researcher+g2-clo+Explore 3개 병렬) 복원 + 2026-06-25 보완점 추가.
> **저장 이유:** 원 분석이 어디에도 저장 안 돼 세션 끊김으로 소실됐음. 재발 방지용 영구 기록.
> By Rotation = 영국 P2P 명품 의류 대여 앱(50만 유저·£60M 리스팅·7년·$6.5M 투자). 신데렐라 벤치마크 경쟁사.

---

## 0. 한 줄 결론
"미국에서 되니 한국도 된다"는 거의 0의 증명력. By Rotation을 굴리는 세 엔진(Stripe 개인정산 · 사람검증 KYC · 영미 safe harbor)이 **셋 다 한국 국경에서 부서진다.** 더 중요한 발견 — 신데렐라는 "한국판 By Rotation"이 아니다. **결제는 더 영리하게(한국 적법) 비켜갔지만, 진품·약관에서는 By Rotation보다 더 센 걸 약속하고 아무것도 안 만든 상태.** 이게 심사 블로커의 정체.

## 1. 구조적 차이 — 신뢰의 축
| | By Rotation | 신데렐라 |
|---|---|---|
| 신뢰의 축 | **사람을 검증**(Stripe Identity 여권+셀피 KYC). 물건은 감정 안 함 | 사람도 물건도 코드상 검증 안 함. 단 약관은 "감정서 제출 의무"로 물건검증 강제 명시 |
| 결과 | 일관 — "사람 추적 가능 → 책임은 개인" | **모순** — 약관은 더 엄격, 코드는 더 허술 → 심사관이 "약관-앱 불일치 = 위조품 앱"으로 판단 |

By Rotation = "물건 무검증 + 사람 강검증"으로 일관. 신데렐라 = "물건 강검증 약속 + 실제론 둘 다 무검증" = 최악 조합.

## 3. 법률 비교 — 진짜 병목 3개
By Rotation이 영미서 도는 건 규제가 없어서가 아니라 그 나라 인프라·법체계에 딱 맞게 짜였기 때문. 그 맞춤이 한국에서 풀린다.

- **① 결제 — Stripe Connect 한국 개인 정산 불가(가장 단단한 벽):** By Rotation의 심장. Stripe는 한국 개인사업자 없이 개인 정산 불가. 복제 시 결제부터 못 켬. → 신데렐라는 이미 우회(토스 딥링크 직송금). 대가: 수익 포착 0, 구매자 보호 0.
- **② 위조품 — 영미 safe harbor가 한국엔 없음:** **상표법 제108조** — 플랫폼이 위조 인지 후 방치 = 방조(백화점 판례의 P2P 확장). → 신고→48h 임시비공개→삭제 프로세스가 운영 첫날부터 필요.
- **③ 통신판매중개업 — CLO 재검토(2026-07-19):** 신고의무 수범자는 **판매 당사자(통신판매업자)**이며 **통신판매중개자는 원칙적으로 신고의무 없음**. 신데렐라=자체재고 0 순수 중개자 → 신고 불요가 원칙(예방적 신고는 선택). 기존 '§20조의3·1년 이하 징역' 표기는 근거 약함(벌칙=3천만원 이하 벌금만 확인). ⚠️ 향후 유료화 시 재검토·실변호사 확인.

## 4. 보완점 (2026-06-25 추가 — 그 세션 권고를 넘어선 것)

### A. 법률 보완점 (출시 차단 해소 순)
1. 🔴 **약관 정합화** — 제8조 "공인감정서 의무" → "신고기반 사후검수"로 교정. = By Rotation 실제 방식 + 한국 최소요건. 심사 리젝 + 상표법 방조 동시 해소. **Alpha 즉시 가능.**
2. 🔴 **위조품 신고→삭제 프로세스** 약관·운영정책 명문화. (신고 기능 ReportSheet.tsx 이미 구현 — 정책 문구만 부착)
3. 🟡 (선택) **예방적 통신판매중개업 신고** — 법인 후. ※원칙적 의무 아님(CLO 2026-07-19).
4. 🟡 **iOS 노리면 Apple Sign In 추가** — 없으면 애플 100% 리젝.
5. 🆕 **개인정보 최소수집** — 향후 본인인증 도입 시 PASS 인증값만 수신, 신분증 원본·주민번호 저장 금지(**개인정보보호법 제24조의2** 주민번호 처리 제한).
6. 🆕 **보증금 = 개인 직거래 유지** — 플랫폼이 보증금을 보관하면 예치금 성격 → **전자금융거래법** 자금보관 규제 발동 가능. 보증금도 개인↔개인 직거래로 둬야 적법.
7. 🆕 **"정품 보장" 표현 금지** — 플랫폼이 "정품 보장"이라 쓰면 **표시광고법** 책임 발생. "개인간 거래, 정품 보장 아님" 명시.

### B. 기능 보완점 (신뢰 격차 메우기)
1. 🆕 **진품검증의 한국형 대안** — By Rotation은 "사람검증"으로 갔으나 신데렐라는 둘 다 안 함. 보완: ⓐ대여자(페어리) PASS/통신사 본인인증(한국은 Stripe Identity보다 싸고 적법) ⓑ물건은 신고기반 사후검수 + 고가품 선택적 외부감정 제휴(라벨·한국명품감정원 등) 옵션.
2. 🆕 **구매자 보호 지렛대** — 결제를 안 거치니 분쟁 시 플랫폼 개입 수단 0. 보완: 거래 증거사진 타임스탬프 + 분쟁 중재 룰 명문화. 장기적으로 국내 PG 에스크로 도입.
3. 🆕 **콜드스타트 신뢰** — 온도점수는 강점이나 DB 0건이면 신뢰지표가 비어 무용. 보완: 초기 직접 큐레이션 페어리 N명 시딩 + 검증 뱃지.

### C. 결제 — 손대지 말 것
🟢 지금 구조(플랫폼 무자금·토스 딥링크) 유지가 정답. 과금은 유저·물량 붙은 뒤 국내 PG로. **By Rotation식 Stripe 복제 시도 금지.**
